Privacy Policy — Carcassonne Tile Tracker

Last updated: July 1, 2026

What this extension does

Carcassonne Tile Tracker is a Chrome extension that reads the game state of a Carcassonne match on boardgamearena.com and displays a floating panel showing which tiles remain in the draw pile, along with draw probabilities. It is intended for use by players and for tutorial purposes.

Data collection

This extension does not collect, store, transmit, or share any personal data. All processing happens locally in your browser.

Website access

The extension reads the game state object exposed by boardgamearena.com in your browser tab. This data is used solely to compute remaining tile counts and draw probabilities displayed in the panel. No data leaves your device.

Third-party services

This extension does not use any analytics, tracking, or third-party services.
