🏰 Carcassonne Tile Tracker

Know what tiles remain. Play smarter on Board Game Arena.

Chrome Extension · Base Game

What it does

Carcassonne Tile Tracker is a Chrome extension that reads the live game state of your Carcassonne match on boardgamearena.com and displays a floating panel showing every tile type still in the draw pile — along with two key probabilities to help you plan ahead.

🃏

Remaining counts

See how many copies of each of the 24 tile types are left.

🎯

Next draw %

Chance the very next tile drawn from the deck is a specific type.

📈

2-player game %

Probability you'll draw at least one copy before the game ends.

✋

Hand-aware

Accounts for whose turn it is to draw — yours or your opponent's.

How to install

  • Download and unzip the latest release from the GitHub releases page.
  • Open Chrome and go to chrome://extensions.
  • Enable Developer mode (top right toggle).
  • Click Load unpacked and select the unzipped dist/ folder.
  • Open a Carcassonne game on boardgamearena.com — the 🏰 button appears at the bottom-left.

How it works

The extension injects a small script into the BGA game iframe that hooks into BGA's own notification system. When a tile is placed, it reads the updated game state directly from the page — no network requests, no external servers. All computation happens locally in your browser.
